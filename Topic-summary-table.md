# AZ-900 — Topic Summary

## TIER-1

| No. | Topic | Definition / Key Point |
|---|---|---|
| 1 | Cloud Service Models | Three main cloud service models: **IaaS, PaaS, SaaS**. |
| 2 | Cloud Deployment Models | **Public cloud:** Shared infrastructure managed by provider. **Private cloud:** Dedicated to one organization. **Hybrid cloud:** Combination of public and private environments. |
| 3 | Shared Responsibility Model | Security responsibilities are **shared between Microsoft and the customer**. |
| 4 | Azure Regions | A **geographic area** containing one or more Azure datacenters. |
| 5 | Availability Zones | **Physically separate locations within an Azure region**, with independent power, cooling, and networking. |
| 6 | Resource Groups | A **logical container for Azure resources**. |
| 7 | Subscriptions | A **management and billing boundary** for Azure resources. |
| 8 | Management Groups | Used to **organize multiple Azure subscriptions**. |
| 9 | Azure Virtual Machines | Provides a **virtualized computer/server in Azure**. |
| 10 | Containers | Package an application and its dependencies into a **portable unit**. |
| 11 | Azure Functions | A **serverless, event-driven compute service**. |
| 12 | VNet | Azure Virtual Network provides **private networking for Azure resources**. |
| 13 | Subnets | A **smaller network segment inside a VNet**. |
| 14 | VNet Peering | Connects two Azure VNets so resources can communicate privately. |
| 15 | VPN Gateway vs ExpressRoute | **VPN Gateway:** Encrypted connection over public internet. **ExpressRoute:** Private dedicated connection to Microsoft cloud services. |

## TIER-2

| No. | Topic | Definition / Key Point |
|---|---|---|
| 1 | VM Scale Sets | **VMSS** allows you to create and manage a **group of identical VMs**. |
| 2 | Availability Sets | Organize VMs to reduce the impact of **planned/unplanned maintenance and hardware failures**. Use **Fault domains** and **Update domains**. |
| 3 | Azure Virtual Desktop | **Cloud-based desktop and application virtualization service** that allows users to access Windows desktops/apps remotely. |
| 4 | Azure DNS | A **DNS hosting service** that hosts DNS domains using Azure infrastructure. DNS translates names into IP addresses. |
| 5 | Azure Files | Provides **fully managed file shares in the cloud**. Supports protocols such as SMB. |
| 6 | Queue Storage | Provides **asynchronous message storage** between application components. |
| 7 | Table Storage | A **NoSQL key-value store** for structured, non-relational data. |
| 8 | AzCopy | A **command-line utility** for copying data to and from Azure Storage. |
| 9 | Storage Explorer | A **graphical tool** for managing Azure Storage. |
| 10 | Azure Migrate | Helps organizations **discover, assess, and migrate workloads to Azure**. |
